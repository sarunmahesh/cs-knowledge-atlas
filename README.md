# CS Knowledge Atlas

A static, responsive, evidence-led Customer Success and CX Enablement research website. No build dependencies.

## Deploy to a NEW GitHub repository

1. Create a public repository named `cs-knowledge-atlas` on GitHub.
2. Upload `index.html`, `styles.css`, `app.js`, `resources.json`, and `.nojekyll` to the repository root (not inside an extra folder).
3. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for the Pages workflow to complete, and open the URL displayed in Pages settings.

## Edit content

Edit `resources.json` to add sources. Keep fields: `title`, `publisher`, `year`, `domain`, `type`, `status`, `summary`, `url`. Do not treat a vendor claim as independent empirical evidence. Keep original URLs and mark unreviewed materials as `Review pending`.

## Next development phases

This prototype does not assert that every linked paper or report has been fully audited. Research classifications are editorial metadata, not a formal quality certification.
